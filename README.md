# m!ntmoch! MotionPortfolio

友部佑征（m!ntmoch!）のモーショングラフィックス・ポートフォリオサイト。
`noindex` を付けているので検索には出ず、URLを直接知っている人だけが見られる状態です。

公開URL: https://mm-c2g.github.io/mintmochi_motionportfolio_ver1.0/

---

## ファイル構成

```
index.html        トップページ（ヒーロー / Works / About / Contact）
work-detail.html  作品詳細ページの「空の枠」。中身はJSが流し込む
style.css         全ページ共通のスタイル。冒頭に目次あり

works-data.js     ★ 作品データ。普段編集するのはほぼこのファイルだけ
script.js         全ページ共通の処理（ナビ・スクロール・スプラッシュ・共通の道具）
home.js           トップページ専用（作品カードの生成・カテゴリーフィルター）
work-detail.js    作品詳細ページ専用（?id=**** の作品を画面に流し込む）

assets/
  favicon.svg     ロゴ（ファビコン・Aboutの画像にも使用）
  images/         サムネイル・シーン画像・OG画像
  videos/         サムネイル動画・ヒーロー背景・スプラッシュ
  documents/      配布用のPDFなど
```

読み込み順は必ず **works-data.js → script.js → ページ専用JS**。
script.js で定義した道具（`ASSET_IMG` / `setMultiline` など）を、後続のJSが使うためです。

### このREADMEについて

このファイル（`README.md`）は**自分用の説明書**で、サイトからは一切読み込まれていません。
好きなように書き換えても、サイトが壊れることはありません。Markdown形式なので、
行頭の `#` が見出し、`-` が箇条書きになります。

逆に `works-data.js` は**サイトが直接読むファイル**です。カンマ（`,`）や
引用符（`"`）を消すと作品が表示されなくなるので、編集後はブラウザで表示確認をしてください。

## よくある作業

### 作品を追加する

`works-data.js` の `works` 配列に、既存のブロック（`{` から `}` まで）をコピーして貼り付け、中身を書き換えます。
**配列に書いた順番が、そのままトップページの表示順**になります。

### 作品の並び順を変える

`works-data.js` の中で、作品のブロックごと上下に移動します。
ブロックとブロックの間のカンマ（`,`）を消さないよう注意してください。

### 文言だけ直す

`works-data.js` の `summary`（詳細ページ冒頭の1行）と `description`（本文）を書き換えます。
`description` の中の `\n` が改行になります。

### 色・角丸を変える

`style.css` の冒頭「01. 変数」にまとまっています。ここを直せばサイト全体に反映されます。

## 仕様メモ

- **作品コード（`code`）** は URL の識別子（`work-detail.html?id=****`）なので、公開後は変更しないこと。
  先頭4桁は「年下2桁＋月」で、詳細ページの「制作時期」に自動変換されます（例: `2512EZ2` → 2025年12月）。
- **サムネイル動画** は `preload="none"` にしてあり、PCはホバー時、スマホは画面に入った時に初めて読み込まれます。
  最初の表示を軽くするための仕組みなので、`poster`（静止画）は必ず指定してください。
- **スプラッシュ動画** はそのブラウザで1回だけ再生されます（`sessionStorage` で記憶）。
- **スクロールはブラウザ標準**です。以前はホイール操作を乗っ取って自前で補間していましたが、
  動きが重くなるうえ、YouTube 埋め込みの上ではイベントが親ページに届かず、そこだけ感度が変わって
  しまうため廃止しました。`#works` などページ内リンクのジャンプだけ、CSS の `scroll-behavior: smooth`
  で滑らかにしています。
